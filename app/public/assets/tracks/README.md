# Bundled tracks

One folder per track, named by slug. Each folder MUST contain:

| File | Purpose |
| --- | --- |
| `audio.mp3` | The track. Only CC0 or CC-BY licensed music; record attribution below. |
| `easy.json`, `normal.json`, `hard.json` | `BeatmapV1` generated by `npm run beatmaps` (docs/09-beatmap-format.md §Bundled tracks). |
| `cover.webp` | 512×512 cover art. |

`manifest.json` at this level lists the slugs and metadata shown in Song Select.
